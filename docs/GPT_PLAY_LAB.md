# GPT 플레이

화면녹화 탭의 `GPT 플레이` 버튼 또는 같은 이름의 탭에서 사용합니다.
기존 녹화 분석과 별도 기능입니다. 연결 ON은 실시간 플레이의 필요 조건이며
자동 시작이나 전체 PC 조작 허용을 뜻하지 않습니다.

## 사용 순서

1. 테스트 PC 또는 격리 환경에서 WinCro와 게임을 실행합니다. 메인 PC에서는
   시작하지 않습니다. 기존 플랜·특화모드 테스트·녹화를 먼저 중지합니다.
2. 화면녹화의 GPT 연결을 ON으로 만들고 GPT 플레이를 엽니다.
3. 새로고침 후 대상 게임 창 하나를 선택합니다. 목표와 허용 키를 입력합니다.
4. 테스트 환경 확인 후 `GPT 플레이 시작`을 누릅니다. 대상 창을 앞으로 가져올
   수 없으면 입력하지 않고 대기합니다. 직접 게임을 선택한 뒤 `계속`을 누릅니다.
5. GPT가 확인하기 어려운 상황이면 장면과 질문이 표시됩니다. 답변을 입력하고
   `답변 후 계속`을 누릅니다. 이전 화면으로 바로 입력하지 않고 다시 관찰합니다.
6. 완료 가능한 후보는 양방향 대조, 독립 후보 재생 3회, 실제 결과 관찰을 거쳐
   새 이름·ID로 동작분석에 등록됩니다. 기존 재생목록에는 자동 편입하지 않습니다.

## 현재 지원 경계

- GPT의 실시간 관찰, 단일 방향/스킬 키 탭, 왼쪽 클릭, 2초 이내 대기, 질문,
  답변 반영, 근거 기록을 지원합니다. 입력은 WinCro InputController로 전달합니다.
- Arduino는 이미 연결되어 있고 KQ 원자 키 입력을 지원해야 합니다. GPT 플레이가
  펌웨어를 갱신하거나 소프트웨어 입력으로 몰래 대체하지 않습니다.
- 기존 설정의 Arduino 필수 조건도 유지합니다. 소프트웨어 입력은 해당 필수 조건과
  Arduino 사용이 모두 꺼진 환경에서만 가능합니다. 테스트 과정에서 사용자 설정을
  변경하지 않았습니다.
- Arduino 마우스는 MM 지원도 필요합니다. 전용 경로는 공용 자동 재연결 함수를
  호출하지 않습니다. 현재 KQ 펌웨어의 키 유지 시간은 6ms이므로 게임에 따라 짧은
  입력을 놓칠 수 있습니다. 실제 게임·장치 확인 없이 방향키 동작을 보장하지 않습니다.
- 긴 누르기, 동시 이동·스킬, OS 조합키, 프로그램 실행, 다른 창 조작은 지원하지
  않습니다. 게임 특성상 필수라면 현재 버전에서 완료할 수 없습니다.
- F1~F12는 WinCro 단축키와 충돌하므로 모델 입력에서 제외합니다. F12는 사용자의
  긴급 중지 키입니다. 초기 버전은 가상 화면 원점이 (0,0)인 주 모니터 안의 창으로
  제한합니다. 기존 다중 모니터 인식 알고리즘은 바꾸지 않습니다.
- 독립 플랜 후보는 이미지 클릭·단일 키·대기·유한 반복만 지원합니다. 기존 기본
  액션 형식으로 저장하며 기본 액션 실행·반복 코드는 기존 RuleExecutor를 사용합니다.
  검수 어댑터는 입력 범위/단일 일치/원자 입력을 추가 확인합니다. 전체 그룹 재생,
  일반 UI 시작/종료, 실제 배포 PC의 장치 차이까지 검증한 것은 아닙니다.
- 임의 조건 분기, 죽음/부활/복귀의 동적 전략, 실시간 GPT 판단이 계속 필요한
  행동은 자동으로 완성 플랜인 것처럼 저장하지 않습니다. 관찰은 가능하나 후보
  형식으로 표현할 수 없으면 미완료로 남습니다. 복잡한 게임 완전 자동화는 아직
  검증되지 않았으며, 지원 분기 스키마 확장은 별도 후속 단계입니다.
- 15분/500입력/600장/화면 근거 128MB의 세션 한도가 있습니다. 오래된 화면(20초),
  창 이동·종료·포커스 상실, 연결 OFF는 추가 입력을 거부합니다. 게임 자체를
  일시정지시키지는 않습니다. 모델 추론 지연 때문에 빠른 전투 반응은 보장하지 않습니다.
- 후보 검수 중 GPT는 관찰만 합니다. 키/마우스 개입을 허용하지 않으며 중지·질문
  대기·입력 실패가 발생한 실행을 독립 성공으로 인정하지 않습니다.
- 기존 플레이와의 입구 경합은 프로세스 내에서 차단합니다. 다른 WinCro 프로세스,
  외부 매크로, 사람이 직접 보내는 입력까지 소유권으로 막을 수 없습니다. 별도
  테스트 PC에서 WinCro 한 인스턴스만 실행해야 합니다. 독립 특화모드 창은 닫습니다.

## 저장·기록

세션은 `%LOCALAPPDATA%/WinCro/recording_analysis/<인스턴스>/gpt_play/session_*`
아래에 보관합니다. 질문/답변·장면·입력 영수증·후보·검수·등록 영수증을 저장합니다.
앱을 닫으면 입력은 중지됩니다. 재시작 후 이전 실시간 세션의 자동 재접속/자동 실행은
하지 않습니다. 저장된 기록은 보관되며 기존 녹화 파일을 생성·수정하지 않습니다.

새 등록은 충돌 시 실패하며 기존 파일을 덮어쓰지 않습니다. `user_verified=true`는
기존 플레이 목록 표시 허용값이며 사람이 검수했다는 뜻이 아닙니다. 별도 영수증에
`user_reviewed=false`를 기록합니다. 분석 기록·3회 성공만으로 완벽성을 보장하지 않습니다.

## 검수 구분

시뮬레이션은 실제 GPT 추론이나 게임 성공의 증거가 아닙니다. Windows CI에서는
독립 UI, 인증 파이프, 가짜 장치와 게임 상태, 기존 액션 처리 연결을 검사합니다.
실제 사용자 게임·Arduino 하드웨어·완성 플랜의 전체 그룹 재생은 별도 현장 검수
전에는 미검증입니다. 이번 구현은 버전 배포와 전체 업데이트를 포함하지 않습니다.
