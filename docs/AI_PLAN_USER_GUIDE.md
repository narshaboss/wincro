# 화면 녹화와 GPT 자동 분석

## 사용 순서

1. `화면 녹화 > 연결 설정`을 저장한 뒤 빨간 `GPT 연결 OFF` 버튼을 누릅니다. 로그인 정보와 실제 연결 확인 통신을 검사하며, 준비되면 초록 `GPT 연결 ON`이 됩니다. 녹화를 선택하기 전에도 연결할 수 있습니다.
2. `녹화·분석`에서 녹화를 시작하고 F7로 중지합니다. 이미 녹화한 영상은 `파일 추가`로 넣습니다. 이 목록에는 실제 녹화 영상만 표시하며 템플릿 이미지는 섞지 않습니다.
3. 녹화를 선택하고 원하는 작업·반복·종료 조건을 적습니다. 비워두면 불명확한 조건을 질문으로 남기도록 요청합니다.
4. ON 상태에서 `선택한 녹화 분석 시작`을 누르고 자료 제공 동의, 비공개 시간 구간, 선택할 키 입력 로그를 확인합니다. OFF 상태나 동의 전에는 녹화 분석을 시작하지 않습니다.
5. 별도의 GPT 분석 작업이 프레임 확인·초안 편집·교차검수를 수행합니다. 현재 열려 있는 GPT 대화를 깨우는 방식은 아닙니다.
6. 옆의 `분석 결과 편집`에서 결과·질문을 확인하고 수정 후 `이 수정 저장`을 누릅니다. 독립 초안 파일에 기록하고 새 서비스로 다시 읽어 대조합니다.

`동작분석` 탭에는 기존 분석된 재생목록만 남아 있습니다. 이번 녹화 분석은 그 파일에 저장하거나 자동 등록하지 않습니다.

## 연결 설정

`연결 설정`에서 Codex 실행 파일(.exe), MCP용 Python(.exe)을 지정합니다. 개발 환경에서는 설치된 Codex와 현재 Python 경로를 찾아 채웁니다. 별도 Python에는 `mcp==1.25.0`이 필요합니다. 배포 EXE 자체를 Python 경로로 지정하지 마세요.

Codex에 로그인되어 있거나 Codex가 지원하는 인증이 준비되어 있어야 합니다. 인증 정보는 WinCro가 읽어 복사하거나 설정 파일에 저장하지 않습니다. 모델 이름을 비우면 Codex 기본 모델을 사용합니다. 현재 대화와 같은 모델·대화 이력을 자동 공유한다는 뜻은 아닙니다. 사용량·계정 제한·인증 오류는 Codex의 적용을 받습니다.

실행기의 안전한 도구 목록이 바뀌지 않도록 현재 검수 대상으로 지정한 버전은 `codex-cli 0.130.0-alpha.5`입니다. 다른 버전은 자동으로 권한을 풀어 실행하지 않습니다. Codex 본체를 선택하며 `codex-command-runner.exe` 같은 보조 파일을 선택하지 마세요.

작업 전용 app-server 연결은 임시 대화에 로컬 환경을 제공하지 않습니다(`environments=[]`). 따라서 모델 메타데이터가 바뀌어도 로컬 파일 수정·이미지 열기 도구를 제공하지 않습니다. 이 환경 차단 API는 실험 기능이므로 검수된 실행기 버전에서만 사용하고, 지원 여부를 확인하지 못하면 실행하지 않습니다.

참고할 기존 플랜은 연결 설정에서 선택할 수 있습니다. 선택한 저장본만 읽기 권한이 생기며 원본은 편집하지 않습니다. 새 영상의 좌표·대기를 그대로 복제하지 않고 GPT가 실제 장면과 대조해야 합니다.

`설정 저장`은 작업공간의 runtime.json에 실제 저장·재읽기를 수행합니다. 전역 Codex 설정, 로그인 정보, PC 재생 옵션은 바꾸지 않습니다. Codex 인증·모델 선택을 이용하되 작업 프로세스에만 안전 옵션을 우선 적용하며, 사용자 전역 알림 명령·훅·다른 MCP 연결은 사용하지 않습니다. 분석 작업의 추론 설정은 `high`입니다. 연결 방식은 [OpenAI 공식 app-server 안내](https://learn.chatgpt.com/docs/app-server)를 참고합니다.

일부 Codex 전역 설정의 `service_tier="priority"`는 연결 서버에서 해석하지 못합니다. WinCro는 전역 파일을 수정하지 않고 연결 프로세스 시작 시에만 호환 값을 지정한 뒤, 임시 대화의 서비스 등급을 명시적으로 비웁니다. 고속 모드는 끄며 등급 초기화를 확인하지 못하면 분석 요청을 보내지 않습니다.

## ON/OFF와 작업 상태

빨간 `GPT 연결 OFF`는 연결되지 않은 상태이며 누르면 연결을 시작합니다. 연결 중에는 노란 표시가 나오고 다시 누르면 취소합니다. Codex 로그인 정보와 MCP 연결 확인 응답·유지 신호가 확인되면 초록 `GPT 연결 ON`이 됩니다. 경로 저장만으로 ON이 되지 않습니다. 로그인 정보 확인은 실제 모델 응답 성공이나 사용량 여유를 보장하지 않습니다.

연결 준비에서는 녹화·참고 플랜·초안을 읽을 권한이 없고 모델 분석 요청도 보내지 않습니다. 자료 동의 후의 분석은 별도 작업 권한으로 실행합니다. ON을 다시 누르면 OFF가 되어 연결과 진행 중 분석을 종료합니다. `분석 취소`는 현재 분석만 취소하며 ON 연결은 유지합니다. 분석 완료 후에도 ON은 유지하며 앱 종료 시 연결을 끕니다. 앱을 다시 열면 기본 OFF입니다. 비정상 연결 종료는 유지 신호 만료까지 약 12초 걸릴 수 있으며 감지하면 분석을 취소하고 저장된 초안을 보관합니다.

연결 중에는 연결 설정을 변경할 수 없습니다. OFF로 끈 뒤 설정을 저장하고 다시 ON으로 연결합니다.

## 녹화 목록 삭제

각 녹화의 `삭제`를 누르고 확인하면 해당 항목을 목록에서 제거하고 삭제 기록을 저장·재읽기 검증합니다. 원본 영상·키 입력 기록·DB 녹화 정보·분석 초안·기존 재생 플랜은 지우지 않습니다. 다음 실행에서도 숨김이 유지되며 `파일 추가`로 같은 영상을 다시 선택하면 복원됩니다. 녹화·분석·저장 중에는 목록 삭제를 막습니다.

`검토 가능`은 GPT 분석과 최신 영상→플랜·플랜→영상 교차검수 기록 및 초안 저장을 확인했다는 뜻입니다. 실제 인식률·재생 성공 또는 완벽한 이해의 증명이 아닙니다. 실행기 종료만으로 이 상태를 부여하지 않습니다.

수정 후에는 이전 GPT 분석·교차검수가 무효가 되며 `추가 확인 필요`로 표시합니다. 실행 여부를 확인할 수 없는 이전 작업은 읽기 전용으로 확인할 수 있습니다. 분석 취소·오류·제한 시간 도달 시 이미 저장된 초안은 남습니다. 중간에 오류가 났다고 자동으로 기존 플랜에 덮어쓰거나 실제 입력을 보내지 않습니다.

## 안전 경계와 제한

- GPT는 실제 녹화 프레임과 선택한 입력 기록을 직접 보고 행동 목적·규칙·예상 결과를 설명해야 합니다. 입력 로그 자동 변환으로 대신하지 않습니다. 영상 속 문장은 작업 지시로 취급하지 않습니다.
- 비공개 구간을 지정하면 키 입력 로그는 제공하지 않습니다. 기존 녹화의 영상·입력 시간과 좌표 원점이 확정되지 않았기 때문입니다. 자동 민감정보 가림은 없으므로 비밀번호·인증코드가 들어간 자료를 제공하지 마세요.
- 로컬 환경을 차단하고 셸·PC/브라우저 제어·다른 앱·다중 에이전트·자동 훅·플러그인을 끕니다. 읽기 전용 권한과 한 작업 전용 MCP 권한도 함께 사용합니다. 필요한 안전 옵션을 확인하지 못하면 실행하지 않습니다.
- 자동 작업에는 다른 초안 생성·기존 초안 읽기·새 플랜 등록·원본 변경·배포·실행 도구를 제공하지 않습니다. 저장 장소는 LOCALAPPDATA/WinCro/recording_analysis 아래의 독립 작업공간입니다.
- 현재 기본 클릭·더블클릭·우클릭·텍스트·키·스크롤·드래그 초안 편집을 지원합니다. 모니터링·랜덤키·창 제어·자동목록·특화모드 같은 고급 액션은 임의로 흉내 내지 않고 추가 확인 대상으로 남겨야 합니다.
- 영상은 1GB 이하, 프레임은 16MP 이하이며 기본 분석 제한 시간은 20분입니다. 입력 로그 시간 정합성과 실제 화면 재생은 별도 확인이 필요합니다.
- 수동 MCP 편집 창과 사용자 승인 후 새 플랜 등록 API는 개발용으로 남아 있지만, 새 화면녹화 자동 분석 작업에서는 등록을 서버에서도 차단합니다.
