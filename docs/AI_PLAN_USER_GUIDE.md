# GPT로 플랜 만들기: 처음 사용하는 방법

**장면을 보고 행동·규칙을 분석하는 담당은 GPT입니다. WinCro는 선택한 자료 전달, 독립 초안 편집, 저장을 담당합니다.** WinCro 안에 GPT 모델이 내장되어 있거나 버튼 하나로 분석이 자동 시작되는 기능은 아닙니다.

## 1. 준비하기

설정에서 `GPT로 플랜 만들기 · 사용방법 / 초안 편집`을 엽니다. 이 창의 `사용방법`에서도 같은 순서를 확인할 수 있습니다.

`녹화 / 이미지 추가`로 따라 만들 작업의 파일을 선택합니다. 비밀번호·인증코드가 없는지 확인하고 동의해야 자료가 추가됩니다. 공개하지 않을 시간은 `0-5,12-18`처럼 초 단위로 지정합니다. 제외 구간이 있으면 시간 오차로 키 입력이 노출되지 않도록 입력 기록을 함께 제공하지 않습니다. 자동 민감정보 가림 기능은 없습니다.

참고할 기존 플랜은 선택 사항입니다. 참고 선택은 원본 수정이나 실행을 뜻하지 않습니다. 녹화가 없어도 기존 플랜을 분석해 달라고 할 수 있지만 실제 영상 대조·제작 완료로 처리할 수는 없습니다.

## 2. GPT 연결하기

`연결 준비 켜기`를 누르고 `연결 설정 안내`를 읽습니다. 준비만 켠 상태는 **GPT 연결 OFF**입니다.

로컬 MCP 연결을 지원하는 외부 GPT 도구에 편집 서버를 등록해야 합니다. 별도 Python과 MCP 실행 환경이 필요합니다. 처음에는 `연결 설정 요청문 복사`를 이용해 설정을 도와 달라고 요청할 수 있습니다. 이 버튼은 외부 도구 설정을 자동 변경하지 않습니다. 로컬 STDIO MCP 서버의 명령·인자 등록 방식은 [OpenAI 공식 MCP 안내](https://developers.openai.com/codex/mcp)를 참고합니다.

연결 정보 파일은 업로드하거나 내용을 공개하지 마세요. 인증 키가 들어 있습니다. 안내 화면은 파일 내용이 아니라 로컬 경로만 보여주고 복사합니다. 이 설치에 서버 스크립트가 없다면 별도 도구 설치가 필요하다고 표시합니다.

등록 후 GPT에게 WinCro의 `connection_status` 도구를 호출해 달라고 요청합니다. 통신과 연결 확인 응답이 들어오면 **GPT 연결 ON**으로 바뀝니다. ON은 연결 상태이지 분석 중이라는 뜻은 아닙니다. 연결이 끊기면 OFF로 돌아갑니다. 비정상 종료는 마지막 확인 신호로부터 약 12초까지 걸릴 수 있습니다.

다른 참고 플랜을 허용하려면 연결 준비를 끄고 선택한 뒤 다시 켭니다. 다시 켜면 연결 경로가 바뀌므로 외부 도구에도 새 경로로 설정해야 합니다.

## 3. GPT에 작업 요청하기

원하는 동작과 반복·종료 조건을 적습니다. 예: `재료가 남아 있으면 계속 제작하고, 더 만들 수 없으면 종료해 줘. 불분명한 동작은 먼저 질문해 줘.`

연결 ON 상태에서 `GPT 요청문 복사`를 눌러 연결된 GPT 대화에 붙여넣어 보내세요. 자동 전송하지 않습니다. 복사용 입력란 자체는 파일에 저장되지 않으므로 긴 설명은 GPT 대화에서 보관하세요.

GPT는 녹화 장면과 입력 맥락을 직접 보고 목적별 액션 묶음·이미지·범위·키·대기를 구성합니다. 편집 뒤 영상 → 플랜, 플랜 → 영상을 반복 대조하고 틀린 부분은 수정한 뒤 다시 검수해야 합니다.

## 4. 초안 확인·저장하기

`초안 검토`에서 초안을 고르고 액션 순서를 확인합니다. `GPT 분석·검수 요약 보기`에는 동작 목적·기대 결과·남은 질문을 쉬운 문장으로 표시합니다. JSON은 `고급: 원본 설정 보기`로 따로 확인합니다.

대기·반복 등 직접 바꾼 값은 `이 수정 저장`을 눌러 초안 파일에 기록합니다. 수정 중인 값과 GPT 변경이 충돌하면 덮어쓰지 않고 입력을 보관합니다. 최신값을 확인한 뒤 다시 수정하세요. 수정하면 이전 GPT 분석·교차검수는 무효가 됩니다.

`초안 저장`은 작업 파일 보관과 재읽기 확인입니다. `새 플랜 등록`은 별도로 사용자 승인 후 일반 플랜 목록에 독립 사본을 추가합니다. 최신 GPT 분석·양방향 검수와 파일 검사를 거치지 못하면 등록하지 않습니다. 원본·재생목록은 자동 변경하지 않습니다.

현재 일반 액션 편집 중심입니다. 모니터링·자동목록 편집과 특화모드 포함 플랜 등록은 아직 지원하지 않습니다. 구조 검사·GPT 검수 기록이 있어도 실제 인식·재생 성공을 보장하지 않으므로, 등록 후 별도의 안전한 환경에서 실행 테스트가 필요합니다.
