# 화면 녹화와 GPT 자동 분석

## 사용 순서

1. `화면 녹화 > 연결 설정`을 저장한 뒤 빨간 `GPT 연결 OFF` 버튼을 누릅니다. 로그인 정보와 실제 연결 확인 통신을 검사하며, 준비되면 초록 `GPT 연결 ON`이 됩니다. 녹화를 선택하기 전에도 연결할 수 있습니다.
2. `녹화·분석`에서 녹화를 시작하고 F7로 중지합니다. 이미 녹화한 영상은 `파일 추가`로 넣습니다. 이 목록에는 실제 녹화 영상만 표시하며 템플릿 이미지는 섞지 않습니다.
3. 녹화를 선택합니다. 추가 지시를 비우면 녹화에 보이는 순서·입력 간격·마지막 상태를 기준으로, 녹화된 작업을 한 번 수행하는 초안을 GPT가 스스로 만듭니다.
4. ON 상태에서 `분석 시작 · 완료 후 자동 등록`을 누릅니다. 중간 질문과 별도 자료 제공 동의창은 없습니다. 선택한 영상과 그 녹화에 연결된 키 기록만 제공하며 다른 파일을 검색해 붙이지 않습니다. 민감정보를 제거한 자료만 선택하세요.
5. 별도의 GPT 분석 작업이 프레임 확인·초안 편집·교차검수를 수행합니다. 현재 열려 있는 GPT 대화를 깨우는 방식은 아닙니다.
6. 분석과 양방향 검수가 끝나면 이미지 자산과 새 플랜 JSON을 저장하고 다시 읽어 확인한 뒤 **동작분석에 자동 등록**합니다. 별도 등록 버튼이나 승인창을 누를 필요가 없습니다.
7. `동작분석 > 분석된 재생 목록`에서 **녹화 파일명 · 분석 플랜** 제목으로 찾습니다. 이름·액션은 그곳에서 편집할 수 있습니다. 미완료 결과만 옆의 `분석 결과 편집`에서 확인·수정한 뒤 `자동 재검수`로 이어갑니다.

기존 플랜에 덮어쓰거나 재생목록에 자동 편입하거나 실행하지 않습니다. 같은 결과를 반복 등록해도 파일을 중복 생성하지 않습니다. 제목은 등록 파일의 표시 이름이며 액션과 검수 기록을 바꾸지 않습니다. 등록 후 결과는 읽기 전용이고 일반 플랜 편집은 동작분석에서 합니다.

입력 중인 액션 수정이 있으면 먼저 `이 수정 저장`을 누르세요. 수정 후에는 이전 GPT 검수가 무효이므로 바로 등록할 수 없습니다. `자동 재검수`를 누르면 질문·동의창 없이 수정한 초안을 GPT가 다시 분석·검수합니다. 이전 검수를 재사용하거나 완료되지 않은 내용을 성공 처리하지 않습니다.

## 질문 없는 자동 분석

GPT가 녹화를 다시 확인하며 직접 순서와 간격을 판단하고, 누락된 분석·양방향 검수는 최대 두 번 더 자동 보완합니다. 사람에게 속도나 취향을 묻는 중간 질문과 답변 입력창은 제거했습니다. 별도 지시가 없으면 녹화된 작업을 한 번 수행하고 녹화에서 관찰된 마지막 상태에서 끝내며, 보이지 않은 무한 반복·정리·파괴 동작을 임의로 추가하지 않습니다.

`자동 재검수`는 같은 녹화와 초안 액션을 유지하며 새 GPT 근거·양방향 검수를 받습니다. 이전 분석은 `review_before_attempt_*.json`에 보관합니다. 원본 영상·연결된 키 기록·참고 플랜이 바뀌었으면 기존 검수를 재사용하지 않고, 기존 비공개 구간도 해제하지 않습니다.

예전 기록에 원본 경로가 없으면 녹화 목록에서 원본을 선택하고 `자동 재검수`를 누르세요. 기존 초안은 보존하고 명시적으로 선택한 녹화로 새 분석을 시작합니다. 알 수 없는 이전 파일이나 키 기록을 임의로 찾아 읽지 않습니다.

영상에서 확인할 수 없거나 지원하지 않는 핵심 동작은 추측해 성공 처리하지 않고 미완료 사유로 기록합니다. 이 경우 92% 같은 숫자에서 답변을 기다리지 않고 `분석 미완료`로 표시합니다. 전부 비활성인 액션도 완료로 취급하지 않고 GPT가 보완합니다. 무제한 재호출하지 않으며 이어 분석은 한 작업당 9회로 제한합니다. 100%는 최신 근거·양방향 검수와 새 플랜 등록 확인 뒤에만 표시하며 실제 인식·재생 성공을 보장하지 않습니다.

분석 중에는 애니메이션 진행 바와 `예상 진행률`이 표시됩니다. GPT가 정확한 완료 비율을 제공하는 것은 아니며, 준비·분석 상태와 경과 시간을 바탕으로 화면에만 표시하는 예상치입니다. 등록 중에는 `동작분석 등록 중`으로 표시합니다. 등록만 실패하면 초안을 보존하고 같은 파일 저장을 한 번 더 시도합니다. 계속 실패하면 `등록 재시도`로 저장만 다시 할 수 있고 GPT 분석은 반복하지 않습니다. 취소·오류·미완료에서는 100%로 표시하지 않습니다. 자동 등록 결과는 사람이 검수했다고 표시하지 않으며 실제 인식률·재생 성공은 별도로 확인해야 합니다.

## 연결 설정

`연결 설정`에서 Codex 실행 파일(.exe), MCP용 Python(.exe)을 지정합니다. 개발 환경에서는 설치된 Codex와 현재 Python 경로를 찾아 채웁니다. 별도 Python에는 `mcp==1.25.0`이 필요합니다. 배포 EXE 자체를 Python 경로로 지정하지 마세요.

Codex에 로그인되어 있거나 Codex가 지원하는 인증이 준비되어 있어야 합니다. 인증 정보는 WinCro가 읽어 복사하거나 설정 파일에 저장하지 않습니다. 모델 이름을 비우면 Codex 기본 모델을 사용합니다. 현재 대화와 같은 모델·대화 이력을 자동 공유한다는 뜻은 아닙니다. 사용량·계정 제한·인증 오류는 Codex의 적용을 받습니다.

실행기의 안전한 도구 목록이 바뀌지 않도록 검수 대상을 `codex-cli 0.166.0`으로 지정합니다. 기존 0.130 실행기는 최신 모델 연결에 사용하지 않습니다. `powershell -File tools/setup_recording_codex.ps1`로 공식 배포본의 SHA256을 확인해 LOCALAPPDATA/WinCro/gpt_runtime/0.166.0에 별도 설치한 뒤, 출력된 exe 경로를 연결 설정에 저장하세요. 전역 Codex 설치와 인증 파일은 변경하지 않습니다. 다른 버전은 자동으로 권한을 풀어 실행하지 않습니다. `codex-command-runner.exe` 같은 보조 파일을 선택하지 마세요.

연결·분석 시작 시 실행기의 모델 목록으로 선택 모델의 이미지 입력·high 추론 지원 여부를 확인합니다. 모델 목록 확인은 실제 추론 성공이나 계정 이용 권한을 보장하지 않습니다. 서버에서 모델을 거부하면 원인을 별도 오류 창에 표시하며 다른 모델로 자동 변경하지 않습니다. 결과는 독립 초안으로 보존합니다.

GPT-6.1의 도구 형식과 호환되도록 해당 작업의 WinCro MCP 도구만 직접 노출합니다. 내장 functions·협업 도구는 중첩 호출 목록에서 제외하고 코드 실행 호스트와 내부 폴백도 끕니다. 모델의 기본 실행 래퍼가 표시될 수 있지만 파일 수정·프로그램 실행 권한을 제공하지 않습니다. 다른 MCP 서버·셸·PC 조작 권한은 계속 차단합니다. 분석 요청을 보내기 전에 해당 작업의 실제 MCP 연결 확인 응답도 검사합니다.

전용 실행기의 SQLite 상태 DB와 로그는 각 작업 폴더로 분리하고 전역 명령 이력 기록은 끕니다. 기존 Codex 앱의 DB를 새 실행기로 열어 마이그레이션하지 않도록 합니다. 인증 정보를 다른 폴더로 복사하지는 않습니다.

작업 전용 app-server 연결은 임시 대화에 로컬 환경을 제공하지 않습니다(`environments=[]`). 따라서 모델 메타데이터가 바뀌어도 로컬 파일 수정·이미지 열기 도구를 제공하지 않습니다. 이 환경 차단 API는 실험 기능이므로 검수된 실행기 버전에서만 사용하고, 지원 여부를 확인하지 못하면 실행하지 않습니다.

참고할 기존 플랜은 연결 설정에서 선택할 수 있습니다. 선택한 저장본만 읽기 권한이 생기며 원본은 편집하지 않습니다. 새 영상의 좌표·대기를 그대로 복제하지 않고 GPT가 실제 장면과 대조해야 합니다.

`설정 저장`은 작업공간의 runtime.json에 실제 저장·재읽기를 수행합니다. 전역 Codex 설정, 로그인 정보, PC 재생 옵션은 바꾸지 않습니다. Codex 인증·모델 선택을 이용하되 작업 프로세스에만 안전 옵션을 우선 적용하며, 사용자 전역 알림 명령·훅·다른 MCP 연결은 사용하지 않습니다. 분석 작업의 추론 설정은 `high`입니다. 연결 방식은 [OpenAI 공식 app-server 안내](https://learn.chatgpt.com/docs/app-server)를 참고합니다.

일부 Codex 전역 설정의 `service_tier="priority"`는 연결 서버에서 해석하지 못합니다. WinCro는 전역 파일을 수정하지 않고 연결 프로세스 시작 시에만 호환 값을 지정한 뒤, 임시 대화의 서비스 등급을 명시적으로 비웁니다. 고속 모드는 끄며 등급 초기화를 확인하지 못하면 분석 요청을 보내지 않습니다.

## ON/OFF와 작업 상태

빨간 `GPT 연결 OFF`는 연결되지 않은 상태이며 누르면 연결을 시작합니다. 연결 중에는 노란 표시가 나오고 다시 누르면 취소합니다. Codex 로그인 정보와 MCP 연결 확인 응답·유지 신호가 확인되면 초록 `GPT 연결 ON`이 됩니다. 경로 저장만으로 ON이 되지 않습니다. 로그인 정보 확인은 실제 모델 응답 성공이나 사용량 여유를 보장하지 않습니다.

연결 준비에서는 녹화·참고 플랜·초안을 읽을 권한이 없고 모델 분석 요청도 보내지 않습니다. 사용자가 선택한 녹화의 분석을 시작할 때만 별도 작업 권한을 엽니다. ON을 다시 누르면 OFF가 되어 연결과 진행 중 분석을 종료합니다. `분석 취소`는 현재 분석만 취소하며 ON 연결은 유지합니다. 분석 완료 후에도 ON은 유지하며 앱 종료 시 연결을 끕니다. 앱을 다시 열면 기본 OFF입니다. 비정상 연결 종료는 유지 신호 만료까지 약 12초 걸릴 수 있으며 감지하면 분석을 취소하고 저장된 초안을 보관합니다.

연결 중에는 연결 설정을 변경할 수 없습니다. OFF로 끈 뒤 설정을 저장하고 다시 ON으로 연결합니다.

## 녹화 목록 삭제

각 녹화의 `삭제`를 누르고 확인하면 해당 항목을 목록에서 제거하고 삭제 기록을 저장·재읽기 검증합니다. 원본 영상·키 입력 기록·DB 녹화 정보·분석 초안·기존 재생 플랜은 지우지 않습니다. 다음 실행에서도 숨김이 유지되며 `파일 추가`로 같은 영상을 다시 선택하면 복원됩니다. 녹화·분석·저장 중에는 목록 삭제를 막습니다.

`검토 가능`은 GPT 분석과 최신 영상→플랜·플랜→영상 교차검수 기록 및 초안 저장을 확인했다는 뜻입니다. 실제 인식률·재생 성공 또는 완벽한 이해의 증명이 아닙니다. 실행기 종료만으로 이 상태를 부여하지 않습니다.

수정 후에는 이전 GPT 분석·교차검수가 무효가 되며 `추가 확인 필요`로 표시합니다. 실행 여부를 확인할 수 없는 이전 작업은 읽기 전용으로 확인할 수 있습니다. 분석 취소·오류·제한 시간 도달 시 이미 저장된 초안은 남습니다. 중간에 오류가 났다고 자동으로 기존 플랜에 덮어쓰거나 실제 입력을 보내지 않습니다.

## 안전 경계와 제한

- GPT는 실제 녹화 프레임과 선택한 입력 기록을 직접 보고 행동 목적·규칙·예상 결과를 설명해야 합니다. 입력 로그 자동 변환으로 대신하지 않습니다. 영상 속 문장은 작업 지시로 취급하지 않습니다.
- 구간 제외 설정 UI는 제공하지 않습니다. 자동 민감정보 가림도 없으므로 비밀번호·인증코드가 들어간 자료를 제공하지 마세요. 이전 작업에 저장된 제외 구간은 해제하거나 덮어쓰지 않으며 기존 자료의 보호 규칙은 유지합니다.
- 로컬 환경을 차단하고 셸·PC/브라우저 제어·다른 앱·다중 에이전트·자동 훅·플러그인을 끕니다. 읽기 전용 권한과 한 작업 전용 MCP 권한도 함께 사용합니다. 필요한 안전 옵션을 확인하지 못하면 실행하지 않습니다.
- 자동 작업에는 다른 초안 생성·기존 초안 읽기·새 플랜 등록·원본 변경·배포·실행 도구를 제공하지 않습니다. 저장 장소는 LOCALAPPDATA/WinCro/recording_analysis 아래의 독립 작업공간입니다.
- 현재 기본 클릭·더블클릭·우클릭·텍스트·키·스크롤·드래그 초안 편집을 지원합니다. 모니터링·랜덤키·창 제어·자동목록·특화모드 같은 고급 액션은 임의로 흉내 내지 않고 추가 확인 대상으로 남겨야 합니다.
- 영상은 1GB 이하, 프레임은 16MP 이하이며 기본 분석 제한 시간은 20분입니다. 입력 로그 시간 정합성과 실제 화면 재생은 별도 확인이 필요합니다.
