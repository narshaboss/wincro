# 창 제어 멀티 후보

## 사용 방법

1. 창 제어 설정 오른쪽 위의 **멀티**를 켭니다.
2. 첫 후보를 선택하고 아래에서 실행 파일명·찾기 방식·제목 조건을 설정합니다.
   위의 실행 중인 창 목록을 누르면 현재 편집 중인 후보의 조건에 반영됩니다.
3. **+ 후보 추가**로 다음 후보를 만들고 같은 방법으로 설정합니다.
   실행 중이 아닌 프로그램은 **직접 입력**으로 파일명을 넣을 수 있습니다.
4. 후보 메뉴로 편집할 항목을 선택하고 **▲ / ▼**로 검색 우선순위를 바꿉니다.
   **후보 삭제**는 선택한 후보만 제거합니다. 최대 20개까지 설정할 수 있습니다.
5. 동작은 모든 후보에 공통입니다. 최대화 / 최소화 / 앞으로 가져오기 중
   하나를 선택하고 **저장**합니다. 저장은 부모 플랜 또는 재생목록까지 기록하고
   재로드를 확인하며, 실패하면 창과 편집 내용이 유지됩니다.

멀티 OFF에서는 기존 단일창 조건을 사용합니다. ON/OFF를 바꿔도 단일창 조건과
후보 목록은 각각 보존됩니다. 단일창을 설정한 적 없는 새 액션이라면 OFF로
저장하기 전에 단일창 조건을 설정해야 합니다.

## 실행 기준

- `1번 엣지 → 2번 미꾸라지`라면 먼저 엣지를 찾습니다. 없으면 대기시간 없이
  바로 미꾸라지를 확인합니다. 처음 발견한 후보 하나만 제어합니다.
- 상태 적용을 기다리는 동안에는 그 후보를 유지합니다. 앞순위 창이 나중에
  나타나도 이미 진행 중인 제어를 빼앗지 않습니다. 선택한 후보가 없어지면
  다른 후보를 다시 확인할 수 있습니다.
- 모든 후보가 없을 때만 기존 S(스킵)를 적용합니다. S ON은 액션에 설정된
  대기시간을 목록 전체에 한 번만 적용하고, S OFF는 계속 목록을 찾습니다.
- 같은 조건에 실제 창이 여러 개 있거나 창 접근·활성화가 거부된 상태는
  '없음'이 아닙니다. 다른 후보로 우회하거나 성공으로 처리하지 않고 재확인합니다.
- 후보 사이와 대기 중에 중지·일시정지를 확인합니다. 일시정지 시간은 스킵
  대기시간에 포함하지 않습니다. 실행 중 설정의 핸들/PID는 저장하지 않습니다.

작은 화면에서는 설정 본문을 스크롤합니다. 저장/취소와 멀티 체크는 본문
밖에 고정되어 있습니다. 편집만으로 대상 창을 조작하지 않습니다.

기존 플랜은 자동으로 멀티로 바뀌지 않습니다. 멀티를 지원하지 않는 구버전은
이 후보 목록을 실행할 수 없으므로, 사용 PC에는 지원 코드도 함께 적용해야 합니다.
