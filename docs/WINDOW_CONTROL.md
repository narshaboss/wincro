# 창 제어

오른쪽 위 `액션 호출 / 자동 목록 처리` 아래의 `창 제어`를 누릅니다.
목록에서 대상 창을 선택하고, 재부팅 후에도 유지되는 제목 일부를 지정합니다.
파일명은 실행 경로가 아닌 `chrome.exe`, `msedge.exe` 같은 이름입니다.
미꾸라지 페이지라면 미꾸라지 실행 파일이 아니라 실제 페이지를 표시하는
브라우저 창을 선택합니다.

찾기 방식은 두 가지입니다.

- 실행 파일명 + 창 제목: 기존 방식입니다. 실행 파일과 제목 일부가 모두 일치해야 합니다.
- 실행 파일명만: 이벤트/업데이트 페이지처럼 제목이 바뀌는 경우에 사용합니다.
  제목 입력란은 사용하지 않으며 같은 실행 파일의 실제 창이 하나일 때 처리합니다.

기존 저장 액션은 자동으로 바뀌지 않습니다. 이벤트 페이지 대응이 필요한 액션의
설정에서 `실행 파일명만`을 선택하고 저장하세요. 탭이 여러 개여도 하나의 창이면
처리하지만, 별도 창이 여러 개면 임의로 선택하지 않고 대기합니다.

- 최대화: 최소화를 해제하고 최대화한 뒤 앞으로 가져옵니다.
- 최소화: 지정한 창만 최소화합니다.
- 앞으로 가져오기: 최소화만 해제하고 기존 창 크기는 유지합니다.

`저장`은 현재 플랜 또는 재생목록 전체를 실제 파일/DB에 저장하고 다시 읽어
확인합니다. 상위 편집창의 다른 미저장 변경사항도 함께 저장됩니다.
저장 실패 시 창을 닫지 않으며 변경사항은 편집기에 남아 있습니다.

선택한 찾기 방식의 조건에 일치하는 창이 정확히 하나여야 실행됩니다.
창이 없거나 여러 개이거나 Windows가 활성화를 거부하면 대기하며 재확인합니다.
대기 중에는 중지/일시정지가 가능하고, 플레이 모드의 기존 디코 장시간 정체
알림이 켜져 있으면 그 기준을 그대로 적용합니다.

창 최대화는 페이지 로딩이나 버튼 표시 완료를 뜻하지 않습니다.
기존 이미지 액션은 창 제어 뒤에 그대로 두어 화면 준비를 확인하세요.
브라우저의 다른 탭을 선택하거나 프로그램을 새로 실행하는 기능은 없습니다.
이미 실행 아이콘을 클릭하는 액션이 있는 경우 그 다음, 해당 화면의 첫 이미지
동작 전에 창 제어를 넣습니다. 기존 최소화 액션의 위치는 사용자가 확인해야 합니다.

창 제어는 일반 액션 및 일반 하위 액션으로 사용합니다. 모니터링 전용 액션으로
붙여넣기는 지원하지 않습니다. 기존 플랜에는 자동으로 추가되지 않습니다.
창 제어의 M(모니터링)·c(트리거) 옵션은 사용하지 않습니다. 이미지 조건 없이
창 자체를 준비하는 액션이므로 이 옵션으로 창 준비를 우회할 수 없습니다.

다른 PC에서 브라우저 종류나 창 제목이 다르면 대상 조건을 맞춰야 합니다.
윈도우 식별자는 매번 다시 찾으므로 저장한 창 번호/PID에 의존하지 않습니다.
Windows의 전면 활성화 제한, 관리자 권한 차이, 응답 없는 프로그램 때문에
준비되지 않는 경우에는 자동 성공이나 임의의 다른 창 선택을 하지 않습니다.
