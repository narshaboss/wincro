# WinCro 1.0.310

- 모니터링 전용 `동영상클릭`의 대표 프레임 선택을 개선해 애니메이션 중간 장면 누락을 줄였습니다. 호환 이름 `동영상 입력`, 반복 클릭과 영상 테스트에도 같은 방식을 적용합니다.
- 등록 영상 199프레임 비교에서 기존 8장 방식의 20개 기준 미달을 새 12장 방식에서 0개로 줄였습니다. 실제 검색 함수에서도 기존 80%, 색상 ON, 밝기 ON으로 199프레임을 검증했습니다.
- 일반 이미지, 일반 동영상 조건, 감시 이미지의 기존 인식 방식과 기준은 유지합니다. 플랜, 액션 순서, 특화모드와 맵은 변경하지 않습니다.
- 전용 영상 실패 원인과 실제 최고 유사도를 진단 로그로 구분합니다. 분석량과 별도 캐시 크기를 제한하고 손상 영상의 오래된 캐시 재사용을 방지합니다.
- 309의 창 제어 멀티 및 우클릭 초기화 수정도 포함합니다. 앱 표시 버전은 1.0.310, EXE 버전은 1.0.310.0입니다.

업데이트 전후 비교와 이후 조사 기준은 `docs/VIDEO_RECOGNITION_BASELINE.md` 및 에이전트 규칙에 기록했습니다. 현장 PC의 배율, 가림, 앞단 95% 감시 이미지와 CPU 지연까지 모두 해결했다는 뜻은 아닙니다.

격리 Windows 회귀검사 후 배포 파일의 코드, 플랜, 버전, SHA-256과 공개 다운로드를 대조합니다. 메인 PC의 창, 입력, 앱과 재시작은 조작하지 않습니다. 개별 PC 설치 완료는 별도 확인 사항입니다. 기존 업데이트의 동일 이름 플랜/맵 덮어쓰기 정책은 변경하지 않습니다.
