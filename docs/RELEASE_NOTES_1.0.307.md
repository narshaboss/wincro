# WinCro 1.0.307

- 플레이모드 디코 알림과 디버그 로그의 하위 액션 번호 불일치 수정.
  성공한 하위 실행 뒤 부모 문맥을 복원하고, 실패는 실제 하위 액션으로
  표시하며, 이전 실행의 지연 콜백이 새 실행 표시를 덮어쓰지 않게 처리.
- 재생목록 저장의 DB 갱신 결과와 재조회 내용 확인. 저장 실패 시
  성공 표시나 수정 표시 해제를 하지 않으며 편집 내용을 유지.
- 읽을 수 없는 설정 원본의 자동 덮어쓰기 차단. 설정은 독립 초안에서
  검증하고 디스크 저장 및 재로드 확인 뒤 적용. 명시적 초기화 전 원본 백업.
- 중지 버튼에서 장치 응답을 동기로 기다리지 않도록 수정. 이전 작업자와
  입력 해제가 끝나기 전에 다음 실행의 입력을 허용하지 않도록 연결부 보강.
- 일반 대기, 반복 대기와 랜덤 텍스트 입력의 중지·일시정지 반응 개선.
- 같은 경로의 이미지 교체와 마스크 삭제 시 인식 캐시 무효화.
- 기존 플랜 순서, 이미지 인식률, 검색범위와 특화모드 알고리즘·맵은 유지.
  창 제어의 기존 S(대상 창 없음 스킵) 설정도 유지.

저장 검증은 임시 JSON 및 실제 SQLite DB 재로드로, 실행 연결부와 알림은
모의 입력·전송으로 검사합니다. UI 및 창 제어 실행 검사는 격리된 Windows
환경에서 수행하며 메인 PC의 실행·입력은 조작하지 않습니다.
실제 Arduino 지연, 게임 장시간 운용, 각 PC의 설치 완료와 휴대폰 진동까지
보장하는 업데이트는 아닙니다. 입력 해제에 실패하면 안전하게 입력을 차단합니다.
