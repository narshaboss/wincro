# WinCro 1.0.309

- 창 제어에 멀티 대상 목록 추가. 등록한 창의 순서, 실행 파일명, 제목 조건을 확인하고 추가, 삭제, 순서 변경할 수 있습니다.
- 멀티는 순서대로 찾아 처음 발견한 창 하나만 제어합니다. 모든 대상이 없을 때 기존 스킵을 적용하며, 멀티 OFF에서는 기존 단일창 방식을 유지합니다.
- 시작, 반복, 종료 시 누르지 않은 마우스 버튼까지 강제로 해제하여 우클릭 메뉴가 열리던 공통 입력 초기화 버그 수정.
- 실제 눌림 상태 또는 누른 기록이 있는 버튼만 해제합니다. 아두이노 안전 해제, 재시도, 입력 고착 방지는 유지합니다.
- 사용자가 저장한 자동사냥 플랜의 창 제어 후보 목록을 그대로 반영합니다. 저장된 멀티 OFF를 자동으로 켜지 않습니다.
- 표시 버전과 실행파일 버전을 1.0.309 / 1.0.309.0으로 통일합니다. 다른 액션 순서와 설정, 특화모드 알고리즘과 맵은 변경하지 않습니다.

격리된 Windows의 회귀, UI, 창 제어 및 우클릭 메뉴 재현 검사 후 배포 파일의 코드, 플랜, 버전, SHA-256을 독립 대조합니다.
메인 PC의 창, 입력, 실행 중 앱과 재시작은 조작하지 않습니다. 릴리스 공개와 개별 PC의 자동 다운로드 및 설치 완료는 구분합니다.
