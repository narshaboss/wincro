==============================================================================
1단계: 대본 채우기
==============================================================================

"최종_완벽_대본_템플릿.txt" 파일을 복사해서 내용 채우기

위치: C:\Projects\wincro\최종_완벽_대본_템플릿.txt


==============================================================================
2단계: 프로젝트 폴더 구성
==============================================================================

새 프로젝트 폴더 생성:

C:\Projects\새프로젝트\
├── 대본.txt        ← 채운 대본 저장
├── PROGRESS.md     ← 진행 상태 (자동 생성됨)
└── CLAUDE.md       ← 프로젝트 컨텍스트 (자동 생성됨)


==============================================================================
3단계: PowerShell 실행
==============================================================================

PowerShell 열고 다음 명령어 입력:

```
cd C:\Projects\새프로젝트
claude --dangerously-skip-permissions
```

※ 권한 경고 나오면 "Yes, I accept" (2번) 선택


==============================================================================
4단계: 프롬프트 붙여넣기
==============================================================================

Claude 대화창에 아래 내용 복사해서 붙여넣기:

────────────────────────────────────────────────────────────────────────────────
대본.txt 파일을 읽고 지시대로 1단계부터 마지막 단계까지 전부 완료해라.

규칙:
1. 각 단계 완료 시 PROGRESS.md 업데이트
2. 에러 발생 시 수정 후 재시도
3. 실제 앱 실행하여 기능 동작 확인
4. 테스트 실패 시 수정 후 재테스트
5. 모든 기능 동작 확인 후에만 완료 처리
6. pip install 등 환경 설정도 직접 실행
7. 패키지 설치, 가상환경 생성 등 환경 설정 먼저 완료

시작해라.
────────────────────────────────────────────────────────────────────────────────


==============================================================================
5단계: 자러 가기
==============================================================================

- PowerShell 창 열어둔 채로 자기
- 컴퓨터 끄지 않기
- 아침에 PROGRESS.md 확인


==============================================================================
아침에 확인할 것
==============================================================================

1. PROGRESS.md 열어서 진행 상태 확인
2. 에러 로그 확인
3. 앱 직접 실행해서 테스트
4. 문제 있으면 Claude에게 수정 요청


==============================================================================
문제 발생 시 이어서 작업하기
==============================================================================

PowerShell에서:

```
cd C:\Projects\새프로젝트
claude --dangerously-skip-permissions
```

Claude에게:

```
PROGRESS.md 읽고 중단된 지점부터 이어서 작업해라.
에러 있으면 수정하고 계속 진행해라.
```
